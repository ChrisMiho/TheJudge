# ai-answer-quality-baseline — 2026-09-07

**What happened:** Ask AI now has a repeatable, human-reviewable way to check
whether the model's final rules answer is actually correct — not just whether
the right rule excerpts reached the prompt. Run `npm run eval:answer-quality
-- --confirm-live-calls` asks four models (`gpt-4.1-mini`, `gpt-4.1`,
`gpt-5-mini`, `gpt-5-nano`) 18 hard rules questions with published official
answers, at both the production excerpt cap of five and a cap of ten, and a
stronger judge (`gpt-5`) scores every answer alone and ranks the answers to
each question blind. The corrected third run — the one that counts, after two
instrument bugs were found and fixed (tier-2 cases had been asked with no
card attached, and no run had actually embedded the question, so every prior
run ranked lexically no matter what) — shows `gpt-4.1`, today's deployed
model, fully correct on 16 of 18 cases at cap five and 18 of 18 at cap ten, at
3.4–3.5 seconds either way.

**What it means for you:** the four models are ranked, the instrument's own
bug is on the record rather than hidden, and there are two concrete follow-ups
waiting: raising the deployed excerpt cap from five to ten as its own package
(REQ-190's measured note is the recorded run that decision needs), and
sampling real production latency against the 3-second target (NFR-002). The
work package is gone from `PRD/work/`; this receipt and the shipped
`PRD/sections/` entries are what's left. The code shipped in PR #203, open
for your merge.
