Four ways to place the page name

Same screen (Zone confirmation), same rail trigger, four different homes for the step-name text — plus what each does to the brand's perceived centering.

Why "off-center" happens: the grid math (1fr auto 1fr) is already exactly centered. What reads as drift is visual weight — a solid glowing rail on the left vs. bare text of varying width on the right. Anything that removes or balances that right-side mass also fixes the centering complaint.
A

Eyebrow above content

Page name leaves the header entirely and becomes a small label sitting right above the step's own heading — travels with the content it describes. Fixes centering by removing the right-side mass outright.

Worth knowing before picking

A and C both remove the top-right chrome entirely, which also frees up real width for long step names ("Context enrichment") that get tight in a corner slot. C goes one step further and removes a whole element by merging with copy that already exists on every step. B keeps the strongest structural symmetry with the trigger rail but is the heaviest visual commitment — two glowing corners on every screen. D is the smallest possible diff from today's layout.

None of these resolve what happens on the Life Tracker / conversation views, where the page-name slot is already empty today — that stays empty in all four.
