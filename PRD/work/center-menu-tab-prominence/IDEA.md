# center-menu-tab-prominence

The center menu tab in the UI is too narrow and under-emphasized. Some users report they never notice it is there, so a primary navigation control is effectively invisible.

Outcome: widen the center tab by about 25% and strengthen the border treatment around its edge so the control reads clearly as an interactive affordance without a full redesign.

Non-goals: not a full nav or tab-bar redesign; not resizing or re-roling other tabs except minor visual balance if required by the center-tab change; no new features or behavior beyond size and border visibility.
