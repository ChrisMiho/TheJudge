# Idea: green-mobile-branch-declutter

## Owner request (verbatim)

"i love this new ui, its unique and fun and gives personality, but for green on mobile, the branches almost seem to clutter the ui over providing ambience, id like to fix this, the current setup has the branches mass overlapping with ui and it looks like a mess"

## Idea

Problem: with the green mana theme on a phone-width screen, the decorative branches pile up over real controls and text, so they read as clutter instead of ambience.
Outcome: green on mobile keeps its branch personality as a quiet backdrop that never competes with or covers the interface; the owner confirms it looks tidy on a phone.
Non-goals: no change to the other mana themes' look, the desktop green look, layout, or behaviour; no new theme or decoration.
