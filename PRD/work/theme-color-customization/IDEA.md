# Idea: Theme Color Customization

**Problem:** The app currently ships with a single fixed blue color theme. There's no way for users to personalize the visual feel of the app, which is a missed opportunity for delight and engagement.

**Outcome:** Users can open a UI control (e.g. a theme/settings affordance) and pick from a set of fun, pre-defined color palettes that restyle the app's primary accent colors away from the default blue. The choice should persist across sessions for that user/browser.

**Non-goals:** Full custom color picker (arbitrary RGB/hex input), per-component theme overrides, server-synced theme preferences across devices, dark/light mode redesign (separate concern unless explicitly folded in later).
