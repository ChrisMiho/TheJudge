# UI flare: chat polish, signature motion, viewport profiles

The staged flow already feels intentional (palette, Chunky/Slim, motion tokens, ambient accents), but the answered conversation view is still a thin bubble list, micro-interactions are uneven, and spacing is mostly mobile-tuned with only ad-hoc desktop overrides. The outcome is a frontend-only polish pass: independent mobile/desktop layout token profiles (density remains a modifier within each profile, not a new knob), a richer chat/conversation presentation with new-message entrances and auto-scroll, a few signature moments (first-answer handoff, palette-switch pulse, theme-panel enter), and consistent use of the existing CSS motion vocabulary. Non-goals: new ThemeControl preferences, animation libraries, palette-tinted page backgrounds, arbitrary RGB pickers, scan-camera internal re-animation, backend/contract changes, and UA-sniffed or separate component trees per platform.
