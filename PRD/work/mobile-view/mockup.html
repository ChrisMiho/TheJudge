Header consolidation — before & after

Two independent floating controls — the top-right theme orb and the answered-view's fallback Menu pill — currently compete for the same mobile header space. The fix folds theme/density into the feature-portal Menu and gives every screen its own inline header slot, so Menu always docks flush and never floats fixed.

Built from the current component code (App.tsx, ThemeControl.tsx, FeaturePortalMenu.tsx, StagedStepHeader.tsx) and the reported screenshot — not final pixels, a layout reference for review ahead of map-out.
