# responsive-containment-and-density

A Playwright MCP sweep of every destination at 390×844 and 1440×900 found that TheJudge's shell leaks in three ways: surfaces clip their own content (the shared question composer pins itself to `height: 0px` and hides 20px of the user's typed question), overlays collide with the page beneath them (the feature tray has no scrim and lets ten page elements ghost through, and its own toggle sits on top of the first menu item), and the layout wastes the space it does own (53% of desktop width and 41–43% of both viewports' height sit empty while the primary "Add card" CTA is stranded 244px below the mobile fold).

Outcome: every destination — Quick Question, In-Depth Question, Life Tracker, Trade Balancer — renders its content fully inside its own box at phone and desktop widths, overlays occlude what they cover instead of blending with it, and the shell uses the viewport it is given instead of pinning a 670px column to the top of a 1440px screen. Each fix is verified with Playwright MCP measurements (`scrollHeight` vs `clientHeight`, bounding-box intersection, viewport-fill ratios) at both viewports before and after, matching the evidence method that produced this idea.

This package absorbs the former `mobile-player-details-overflow` work package: its In-Depth roster containment defect (row content 322px inside a 288px box, disclosure controls 8px past the panel border) reproduces unchanged and is folded in here, and its already-promoted `DEC-128` / `REQ-106` product truth carries forward as inherited scope rather than being re-authored.

Non-goals: no visual redesign of themes, typography, or brand treatment; no changes to Ask AI behavior, prompt assembly, payload shape, stack ordering, or `GameContext` data; no new `@playwright/test` CI harness (Playwright MCP stays the verification path); no changes to disclosure semantics, player-count rules, or conversation-history drawer behavior, which the sweep found already correct and which serves as the reference pattern for the tray fix.
