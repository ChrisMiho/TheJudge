Slice E · desktop shell width

How wide should the app column be?

Every frame is the same Game Context screen at a 1440×900 desktop viewport, drawn to scale. Only the shell's width cap changes. The dashed band marks the shell; mobile is identical in all five and is not affected by this decision.

Today's app ships the 670px column. I shipped 1325px, you called it stretched, and it's currently dialed to 1024px in the working tree — uncommitted.

The five widths

Watch the Confirm game context button — it's the control that reveals the stretch, because nothing in it grows to justify the extra width.

42rem 670px — what ships today
Nothing stretches, but 770px (53% of the screen) is unused. This is the finding that started the package.
