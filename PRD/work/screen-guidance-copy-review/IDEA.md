# IDEA: Screen Guidance & Copy Review

**Problem:** After the AWS release to friends, early feedback surfaced that users struggle to figure out how to use each screen. The current per-screen statements were intended to explain usage but are not landing — players are unsure what to do or why a step matters.

**Outcome:** Review and refine the instructional wording and explanatory copy across the app's screens so a first-time user understands, on each screen, what the screen is for, what action to take, and what happens next. Improve clarity, tone, and placement of guidance without redesigning the flows themselves.

**Non-goals:** Not a flow/interaction redesign, not new features or screens, and not a full visual/layout overhaul. Backend prompt copy and AI-generated explanation text are out of scope except where user-facing UI labels reference them.
