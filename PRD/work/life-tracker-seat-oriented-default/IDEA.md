# Idea: life tracker opens seat-oriented by default

A new Player Life Tracker game opens in grid layout, where every player's `−` is on the screen-left and `+` on the screen-right no matter which edge of the table they sit at. The player gets a tracker that opens in the seat-oriented list layout, so each player's `−`/`+` matches how they sit. Intake evidence suggests this may be a default-layout change, not new layout work, but refinement must confirm that and decide the product truth. Non-goals: removing grid, redesigning either layout, or touching seat-map behavior.
