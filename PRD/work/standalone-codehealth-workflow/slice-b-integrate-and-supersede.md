# Slice B — Integrate and supersede

## Status: planned

## Goal

Wire `codehealth` into the repo and retire `overnight-codehealth`: catalog the new
skill, delete the old one, harden the permission profile against self-modification,
mirror to `.agents/skills/`, and update docs. Depends on Slice A.

## Requirements

1. **Catalog** `codehealth` in `AGENT-SKILLS.md` — add it where the autonomous/loop
   skills belong, following the file's `## Adding or updating a skill` guidance, with
   its trigger, outputs, and entry point (`/loop codehealth`).
2. **Delete** `overnight-codehealth` from `.claude/skills/` (canonical). Its only
   non-worktree references are the two skill copies and historical receipts; receipts
   are immutable history and are not touched.
3. **Harden** `.claude/graph-profile.json`: add deny entries so an armed run cannot
   edit the new skill —
   `Edit(./.claude/skills/codehealth/**)` and `Edit(./.agents/skills/codehealth/**)`
   — mirroring the existing `thejudge-*` skill-edit denials.
4. **Mirror**: run `npm run skills:ai-sync` so `.agents/skills/` reflects both the
   new `codehealth` skill and the removed `overnight-codehealth`. Verify with
   `diff -rq .claude/skills .agents/skills` (expect no output).
5. **Docs**: update any owner-facing references so the entry point is `/loop
   codehealth` (e.g. `README.md` Agent Workflow Skills note and `OPERATOR.md` if they
   name the loop). Do not edit historical receipts.

## Acceptance criteria

- [ ] B1 `codehealth` is cataloged in `AGENT-SKILLS.md`
- [ ] B2 `overnight-codehealth` no longer exists under `.claude/skills/` or `.agents/skills/`
- [ ] B3 `graph-profile.json` denies editing `.claude/skills/codehealth/**` and `.agents/skills/codehealth/**`
- [ ] B4 `npm run skills:ai-sync` run and `diff -rq .claude/skills .agents/skills` is clean
- [ ] B5 `npm run quality:check` is green
