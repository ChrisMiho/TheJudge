# standalone-codehealth-workflow

A standalone, purpose-built `codehealth` overnight loop that replaces
`overnight-codehealth`'s dependence on the graph feature engine. It opens one
behavior-preserving code-health PR per target, never merges, and needs zero graph
changes. See `IDEA.md`, `DESIGN-BRIEF.md`, `GAMEPLAN.md`.
