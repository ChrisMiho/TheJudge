The app's In-Depth, Quick, and Life Tracker flows currently express similar themes with inconsistent color usage, making personalization feel fragmented. Unify those flows around a shared theme system, then replace the current preset palettes with five profiles inspired by Magic's white, blue, black, red, and green colors. Add a sixth colorless profile that defaults to a neutral gray and lets users select a custom color from the full RGB spectrum. The black profile needs visual mocks and contrast exploration so it remains distinct and legible against the app's dark background. This idea does not yet prescribe exact color values, component-level styling, persistence behavior, or the final custom-color picker interaction; those belong in refinement.
