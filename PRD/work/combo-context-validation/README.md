# combo-context-validation

Use the committed Commander Spellbook combo corpus as labeled ground truth to
validate the rules-question pipeline: (A) deterministic case generation to test
the shipped multi-card/partial-combo behavior at scale, and (B) a live diagnostic
that probes whether the broader generated context is good enough — and, on a
wrong answer, which context was missing.

See `IDEA.md` for problem, outcome, non-goals, and the open framing questions.
Follow-up to `prompt-context-refinement`; extends NFR-018.
