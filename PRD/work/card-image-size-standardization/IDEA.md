# Idea: card-image-size-standardization

Card art thumbnails in the zone card list (`ZoneCardPicker`), scan review bubble (`ScanReviewBubble`), and enrichment step (`EnrichmentStep`) are too small to be legible — the scanned printing art that now flows through the app can't actually be read at the current thumbnail sizes. The desired outcome is a consistent, legible card image size across all these surfaces, visually calibrated to the `CardSelectionPreview` layout used by manual search as the reference point for "large enough to see the art." Each surface has different layout constraints: `ScanReviewBubble` is a floating 240px-wide panel, `ZoneCardPicker` list rows share space with a card name and remove button, and `EnrichmentStep` has the most room. Non-goals: changing `CardSelectionPreview` itself, altering any data or prompt contract, or touching scan-engine behavior.
