# ai-answer-quality-baseline

Measurable AI answer-quality baseline over the existing backend eval fixtures, so prompt and enrichment changes can be judged as helping or not.

Captured by `thejudge-kickoff` during a cross-package prioritization pass. The
existing harness scores prompt/context structure and retrieval relevance; no
instrument scores the model's answer.

See `IDEA.md` for the original idea and the open shaping questions.
