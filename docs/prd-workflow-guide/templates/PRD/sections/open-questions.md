# open-questions.md

Unresolved items that need a human decision. When an agent hits genuine
ambiguity it writes a `Q-###` here rather than guessing.

IDs are assigned in ascending order and are never reused or renumbered. A
resolved question is answered by writing a `DEC-###`; the `Q-###` entry then
notes which decision resolved it.

---

### Q-001
- Question: <the actual question, answerable as asked>
- Context: <what makes this open; what has already been tried or considered>
- Why it matters: <what goes wrong if it is answered badly, or not at all>
- Options under consideration:
  - <option, with its main tradeoff>
  - <option>
- Recommended next step: <usually "ship the simple option now, revisit when X">
