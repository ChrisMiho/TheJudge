# Tab icon candidates

Three generated favicon/tab-icon candidates for TheJudge, kept as design
reference. None is wired into the app yet — the shipped app has no favicon work
package.

Moved here on 2026-08-10 from `PRD/work/tab-icon/`, where the images sat as a
folder with no `IDEA.md`, no `STATUS.*` marker, and no row on
`PRD/work/STATUS.md`. `PRD/work/` holds ephemeral packages that skills delete on
cleanup, so untracked reference art does not belong there. Filenames were
normalized from their original `ChatGPT Image Aug 6-7, 2026 …` names in
timestamp order.

To actually ship one, open a work package with `thejudge-kickoff` and refine it
from here.
